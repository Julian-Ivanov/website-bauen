# website-bauen

Ein Skill für Claude Code, der dich Schritt für Schritt durch den kompletten Bau einer Website führt: Name und Logo, Recherche mit echten Suchdaten, Texte, Design-Richtung, Bau, Prüfung, Livegang und Nachmessen bei Google und ChatGPT. Funktioniert auch, wenn du noch keinen Namen und kein Logo hast.

## Installieren

Kopiere den Link zu dieser Seite und schreib Claude Code:

```
Installiere den Skill von https://github.com/Julian-Ivanov/website-bauen global, damit er in jedem Projekt verfügbar ist.
```

Danach Claude Code neu starten, einen leeren Projektordner öffnen und eingeben:

```
/website-bauen start
```

## Was du brauchst

- Claude Code oder einen anderen KI-Agenten wie Codex
- impeccable, ein kostenloses Design-Plugin. Der Skill richtet es am Anfang mit dir ein.
- Für die Recherche ein Konto bei DataForSEO, für den Livegang ein Webhosting. Beides richtet der Skill erst in der Phase ein, in der es gebraucht wird.

## Weitermachen und aktualisieren

Der Skill speichert den Stand in der Datei `WEBSITE-STATUS.md` in deinem Projekt. Wenn du ein paar Tage später weitermachst, öffne einen neuen Chat im Projektordner und tippe `/website-bauen weiter`.

Eine neue Version holst du dir, indem du Claude Code schreibst: „Aktualisiere den Skill website-bauen von GitHub.“
