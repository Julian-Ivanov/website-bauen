# Phase 4: Design-Richtung

Ziel: Eine eigene visuelle Welt für genau diese Seite, von der Person gewählt und als Richtungsvertrag festgehalten. Keine Vorlage, kein Standard-Look.

Das ist die Phase, die über „sieht aus wie jede KI-Website“ oder „sieht aus wie meine Marke“ entscheidet.

## Ablauf

1. `/impeccable` mit einem klaren Auftrag starten: Art der Seite (neue Landingpage oder Redesign), Markenprofil aus Phase 1, gewählte Referenzen aus Phase 2, Verweis auf `texte.md`. Eine alte Seite oder ein alter Entwurf nur als Gegenbeispiel nennen. impeccable lädt `PRODUCT.md` selbst.
2. **Sieben eigene Richtungen** aus der Welt der Zielgruppe ableiten, aus mindestens drei verschiedenen Materialfamilien. Für eine Beratung für Mittelständler etwa Prozesslandkarte, technische Zeichnung, Bildfahrplan, Wasserbau, Werkstatt. Die naheliegendste Idee (bei einer Marke namens „Kompass“ wäre das eine Kompassnadel) zählt nur einmal.
3. **Auslosen** mit `concept-seed`: Das Los wählt, welche der sieben gebaut wird, und teilt Herausforderer aus dem Katalog von impeccable zu. So landet man nicht automatisch beim Standard.
4. **Herausforderer ehrlich abwägen.** Verworfene Richtungen geben trotzdem je eine Stärke an die Hauptrichtung ab.
5. **Auswahlseite zeigen.** impeccable baut eine Seite mit Karten (Farben, Materialien, Skizze des ersten Bildschirms). Die Person wählt. Neu würfeln, „sicherer“ und „mutiger“ sind möglich.
6. **Richtungsvertrag** festhalten (impeccable legt ihn unter `.impeccable/surfaces/` ab): These, eigene Welt, Geschichte beim Scrollen, erster Bildschirm, Formensprache, Abschluss.

## Was eine gute Richtung ausmacht

- **Eine Idee trägt die ganze Seite.** Für eine Gärtnerei etwa das Gartenjahr: Die Abschnitte folgen den Jahreszeiten, der Ablauf ist ein Beet, das beim Scrollen wächst. Jedes Element folgt aus derselben Metapher.
- **Die Metapher passt zum Angebot.** Sie erzählt etwas über die Leistung. Eine Metapher ohne Bezug ist Dekoration.
- **Ein übergroßes Element pro Abschnitt**, der Rest ruhig.
- **Der Akzent bleibt selten.** Die Akzentfarbe steht auf wenigen Wörtern, nicht in jeder Überschrift.

## Abnahme

Die Person wählt eine Richtung auf der Auswahlseite. Ohne Wahl wird nicht gebaut.

## Fertig, wenn

- [ ] Sieben Richtungen erarbeitet, mindestens drei Materialfamilien.
- [ ] Die Person hat eine gewählt.
- [ ] Richtungsvertrag liegt im Projekt.
